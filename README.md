# Lotus Heart

Static website for [Lotus Heart Solutions](https://bcprofoundation.github.io/lotus-heart/), cloned from the Carrd original at [lotusheart.carrd.co](https://lotusheart.carrd.co/).

## Preview locally

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).

## GitHub Pages

Enable Pages in the repository settings:

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main` / `/ (root)`

The site will be available at `https://bcprofoundation.github.io/lotus-heart/`.

To use a custom domain such as `lotusheart.solutions`, add a `CNAME` file and point DNS at GitHub Pages.
